# Personal de Bolso — V1.2 SINCRONIZADA

Esta é a versão V1.2 completa, com os três arquivos compatíveis entre si.

## Importante
O print mostrado no teste ainda exibia o botão **EDITAR TREINO**, que pertence à versão anterior. Isso indica que o navegador/GitHub estava usando um `index.html` antigo enquanto a lógica da V1.2 já esperava a nova tela.

Esta versão:
- usa o editor da V1.2;
- remove o botão antigo "EDITAR TREINO";
- mantém "ADICIONAR TREINO";
- mantém histórico, progressão, XP e missão;
- adiciona versionamento `?v=1.2` nos arquivos CSS/JS para reduzir problemas de cache.

## Atualização
No GitHub, substitua os três arquivos juntos:
- index.html
- styles.css
- app.js

Faça Commit changes.

Depois abra o site novamente. Se a página antiga continuar aparecendo, use Ctrl+F5.

Não misture arquivos de versões diferentes.
