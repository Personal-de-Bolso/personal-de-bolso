# Personal de Bolso — V1.1

Protótipo estático e responsivo do Personal de Bolso.

## O que mudou nesta versão
- Cadastro inicial mais completo
- Escolha da personalidade de cobrança
- Entrevista com 9 perguntas para definir o treino
- Pergunta aberta para limitações/exercícios
- Geração contextual de uma primeira rotina
- Dashboard com XP, nível, sequência e missão semanal
- Modo de execução com exercício, série, carga, repetições e timer de descanso
- Persistência local do progresso no navegador

## Publicação
O projeto pode ser hospedado no GitHub Pages. Coloque os arquivos na raiz do repositório e use:
Settings → Pages → Deploy from a branch → main → / (root).

## Próxima evolução
- Integração real com IA por backend seguro
- Editor de treino completo
- Histórico de cargas e repetições
- XP por séries/treino/missões
- Sistema de objetivos semanais
- Alimentação e planejamento de viagens

## Segurança
Nunca coloque uma chave de API de IA diretamente em `app.js` ou em outro arquivo público do GitHub Pages. A integração real deverá passar por backend/serverless.
